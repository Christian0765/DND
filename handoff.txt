FIRESTORE RULES
--------------------------------------------------------------------------------
Rules file: /firestore.rules in the repo.
IMPORTANT: GitHub Pages does NOT auto-deploy Firestore rules.
You must manually paste the rules into Firebase Console each time they change:
  Console → Firestore Database → Rules tab → Paste → Publish

Current rules summary:
  characters/{charId}  — signed-in users can read; DM or owning player can write
  users/{uid}          — DM can read all; each user reads/writes their own doc
  campaign/{doc}       — anyone can read; only DM can write
  purchases/{id}       — any signed-in user can read/write
  combat/{doc}         — anyone can read; only DM can write

AUTH & ACCESS
--------------------------------------------------------------------------------
Google Sign-In:   Enabled in Firebase Console → Authentication → Sign-in method
DM Passcode:      Stored in localStorage key 'dm-passcode' (default: dm1234)
                  NEVER commit the passcode to Firestore or the repo.
DM Google link:   When DM enters passcode while signed in with Google, their
                  users/{uid}.charId is set to 'dm' automatically.

Player assignment flow:
  1. Player visits site → signs in with Google
  2. Their name appears in DM panel → Manage Players section
  3. DM assigns them to Player 1/2/3/4 via dropdown
  4. Player now sees "Your Sheet →" link and can access their sheet

BROADCAST TYPES (campaign/broadcast.type)
--------------------------------------------------------------------------------
  text        — title + text message
  image       — title + imageUrl
  shop        — title + shopItems (plain text, one per line: "Name: Xgp - Desc")
                Players see Buy buttons; deducts from f-gold, adds to f-equipment
  combat      — triggers "Combat has begun" panel with link to combat.html
  dice        — shows spinning dice corner widget (no main panel)
  initiative  — dramatic staggered reveal of all player initiative rolls
