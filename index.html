🤖 New Player? Convert Your Sheet with AI

Got a handwritten or existing sheet? Copy this prompt, paste it into any AI (Claude, ChatGPT, etc.), then upload a photo or describe your character. The AI will extract everything in the right format for your digital sheet.

AI Conversion Prompt
I have a D&D 5e character sheet I want to digitize. Please extract all the following fields and return them clearly labeled: - Character Name - Class & Level - Race - Background - Alignment - Player Name - Proficiency Bonus - Armor Class, Initiative, Speed - Current HP & Max HP - Hit Dice, Passive Perception, Gold (GP) - All 6 Ability Scores (STR/DEX/CON/INT/WIS/CHA) with modifiers - All Saving Throw bonuses — mark proficient ones - All Skill bonuses — mark proficient ones - All Weapons with attack bonus, damage dice, and type - All Class Features and Racial Abilities with full descriptions - Subclass and Subclass Features - Equipment list - Personality Traits, Ideals, Bonds, Flaws - Backstory notes - Any homebrew abilities or special items with descriptions - Any special weapon lore or progression stages - Treasure and misc items - Proficiencies: Armor, Weapons, Tools, Languages Format each field exactly like: Field Name: Value If anything is unclear or missing, flag it so the player can fill it in manually. Do not guess stats — note anything uncertain.
Tips Upload a clear photo of your sheet for best results. Describe any homebrew items after the prompt. Once the AI returns your data, open your sheet file and fill in each field.
⚙ Setup Instructions — Google Sheets Integration
1
Create a Google Sheet for each player Go to sheets.google.com and create one sheet per player. Name them Player1, Player2, etc. Share each sheet with everyone in the group (Editor access).
2
Open Apps Script on each sheet In each Google Sheet go to Extensions → Apps Script. Delete any existing code and paste in the script below. Click Save, then click Deploy → New Deployment → Web App. Set access to Anyone. Copy the deployment URL.
3
Paste the deployment URLs into each character sheet HTML Each sheet HTML file has a line at the top: const SHEET_URL = "PASTE_YOUR_URL_HERE"; Replace it with the URL from step 2.
4
Host the site on Google Drive Upload all HTML files to a shared Google Drive folder. Right-click each file → Share → Anyone with link can view. Send the index.html link to all players. Done!
5
To add more players Duplicate any sheet-X.html file, increment the number, add a new card to index.html following the same pattern, and repeat steps 1-3 for the new player.
Google Apps Script — paste into each sheet
function doGet(e) { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); const data = sheet.getDataRange().getValues(); const obj = {}; data.forEach(row => { if (row[0]) obj[row[0]] = row[1]; }); return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); } function doPost(e) { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); const params = JSON.parse(e.postData.contents); Object.entries(params).forEach(([key, value]) => { const data = sheet.getDataRange().getValues(); let found = false; for (let i = 0; i < data.length; i++) { if (data[i][0] === key) { sheet.getRange(i + 1, 2).setValue(value); found = true; break; } } if (!found) { sheet.appendRow([key, value]); } }); return ContentService.createTextOutput(JSON.stringify({status:"ok"})) .setMimeType(ContentService.MimeType.JSON); }
